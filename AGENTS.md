# Working on this installation

If available locally, read [HANDOFF.md](HANDOFF.md) before working on the TV setup. It contains private installation details and must stay ignored and untracked. Never stage, commit, or push it.

Read [CLAUDE.md](CLAUDE.md) for the app architecture and installation precautions. User instructions take precedence. Keep private configuration and the signing key local; never print or commit them. Do not reset or clear TV system apps.

Keep personal locations, device addresses, trip dates/destinations, and private feed links in ignored `config.properties`, not source or tracked notes. Use empty/generic values in `config.example.properties`. Put new personal assets under ignored `private/`; builds bundle the configured wallpaper from an ignored local input. Do not publish APKs built with private configuration.

Keep progress messages short. Carry authorized work through build, installation, and appropriate verification. Do not switch the TV's home mode from the computer; the user switches it on the TV.
